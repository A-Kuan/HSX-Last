# HSX SKU 商品库

单人使用的汽配 SKU 资料维护工具。当前范围只包含商品组、SKU、OE 号、车型适配、资料状态和操作记录，不包含库存、仓位、调拨或权限管理。

## 数据结构

- 商品组：商品名称、参考编码、配件品类、图片和说明
- SKU：SKU 编码、品牌、品牌件号（可空，原厂件通常没有）、单位、**产地**（进口/国产）、**渠道**（4S/服务站、平行进口、电商、批发…）、包装数量、销售价（可空，未填显示“面议”）、资料状态和备注
- OE：一个 SKU 可维护多个 OE 号
- 车型适配：品牌、车系、年款、版本、发动机/配置、安装位置、来源和核实状态
- 操作记录：记录新增、编辑和状态变化

数据使用 SQLite 持久化，默认路径为 `data/sku-library.sqlite`。可通过 `SKU_DB_PATH` 修改。

## 商品组维护

- 顶部「商品组」页独立维护商品组：名称、参考编码、配件品类（字典下拉）、安装位置、说明、OE 号
- **组级 OE 号**是判断“是不是同一个件”的依据；SKU 上原有的 OE 会自动上卷到组，SKU 级仍可保留品牌件特有的 OE。同一组可挂多个等价 OE（如 `06L 115 562 B / 06L 115 466 C / 06L 115 562 E`），并可指定**主 OE**（报价时优先显示）
- 「SKU 商品库」的搜索框同时匹配组级 OE：输入 `06L115466C` 或 `06L 115 466 C` 都能命中该组，并列出组内全部品牌
- 新建 SKU 时，如果它填的 OE 已出现在别的组、且两边安装位置一致，抽屉里会给出提示并可一键「改归该组」
- 「合并商品组」：选择并入方与保留方 → 预览影响（移动 SKU 数、车型映射、重复映射、OE 重叠/合并后数量）→ 确认合并；位置不同（如左/右）时禁止合并
- 列表显示每个组的 SKU 数、车型引用数与 OE 数，可按品类筛选、按名称/编码/品类/OE 搜索
- 参考编码全局唯一；删除受保护：组下还有 SKU、或被车型适配件引用时拒绝删除并说明原因
- 接口：`GET/POST /api/groups`、`PUT/DELETE /api/groups/:id`、`POST /api/groups/merge/preview`、`POST /api/groups/merge`

## 车型查询（按车找件）

- 车辆：品牌、车系、代系、平台代号、年款区间、发动机、车身、驱动；每台车可配多个口语别名（如「卡宴 / 凯宴 / Cayenne / E3 / 9YA」）
- 件类与套餐：件类（机油/空气/空调/燃油滤清器）可组合成套餐，「三滤」＝机油＋空气＋空调滤清器
- 车辆 ↔ 商品组：多对多映射，同一商品组可被多台车共用
- 查询：输入「卡宴 E3 三滤」即按套餐里的件类列出各品牌 SKU（只列启用的），未建档的件类会标出来

接口：`GET /api/vehicles`、`GET /api/vehicle-lookup?q=`。**不再写入演示数据**：车型、商品组、SKU 全部从零手动创建；数据库只在初始化时写入件类与套餐这类基础字典（机油/空气/空调/燃油滤清器、三滤/四滤）。测试需要示例数据时显式调用 `seedDemoData(db)`。

## 车型库维护

- 车型全部手动维护：品牌、车系、代系、平台代号、年款区间、发动机、车身、驱动
- 别名可以随手加（「卡宴」「9YA」「C48」这类叫法），查询时按别名命中
- 每台车可以挂多个适配商品组，按件类归类，并标注核实状态和安装位置
- 「VIN 识别录入」入口已就位：校验 17 位 VIN 后提示解码服务尚未接入，转入手动录入；后续接入解码服务即可自动带出车型
- 接口：`POST /api/vehicles`、`PUT /api/vehicles/:id`、`DELETE /api/vehicles/:id`、`GET /api/part-types`

## SKU 替代关系

- 横向互换：不同品牌的等价件，双向都能查到（如曼牌 ↔ 马勒）
- 纵向替代：旧件被新件替代，由人工逐跳维护；系统会顺着替代链给出最终件号
- 循环替代、重复关系会被拒绝；关系在 SKU 详情「替代关系」页签里维护
- 接口：`GET/POST /api/skus/:id/relations`、`DELETE /api/relations/:id`

## 产地与渠道

- SKU 上有两个字典字段：**产地**（进口 / 国产）和**渠道**（4S/服务站、平行进口、电商、批发）
- 在「新增 / 编辑 SKU」抽屉里选择；未选时显示「未标注」，不影响保存
- 列表里跟在品牌件号后面显示（`CONT-001 · 进口 · 4S/服务站`），详情页与目录接口都会返回
- 在「配置中心 → 产地 / 渠道」里维护，改名会级联更新已有 SKU；仍被引用的值不能删除
- 保存 SKU 时出现新值会自动补录进字典

## 本地开发

```bash
npm install
npm run dev
```

`npm run dev` 会同时启动：

- 页面：`http://127.0.0.1:5173/hsx-sku/`
- API：`http://127.0.0.1:4188`

## 构建与测试

```bash
npm run build
npm test
```

## 数据备份

```bash
npm run backup
```

默认备份到 `data/backups/`，生产环境可通过 `SKU_BACKUP_DIR` 指定目录。

## 批量导入与导出

- 页面可下载 CSV 模板，填写后先预览校验，再整批写入
- 导入支持按 SKU 编码更新或仅新增；任意一行失败时整批不写入
- 可导出全部 SKU，勾选 SKU 后则只导出选中项

生产访问路径：`/hsx-sku/`
